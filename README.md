# 资产配置研究平台 V2.3（云端部署版）

基于真实公开指数行情的资产配置研究网页，采用 Python + Streamlit。本目录是**从最新验证代码抽取的独立部署版本**，不含测试、实验、凭证、缓存与历史审查资料。

版本：`v2.3.0` ｜ 本地验证基线：`1e205c3`（含云端兼容性修复）｜ Python 3.13 ｜ Streamlit 1.66.1

---

## 一、研究主线

数据 → 收益与风险 → 两种基础配置 + 两个简单基准 → 统一滚动样本外回测 → 窗口/分年度诊断 → 结果导出。

| 页面 | 内容 |
|---|---|
| 1️⃣ 资产与数据 | 真实行情获取、质量检查、指数口径、标准化净值、数据来源与缓存状态、手动刷新 |
| 2️⃣ 收益与风险 | 算术/几何收益、CAGR、波动率、协方差与相关系数、分散化收益 DR |
| 3️⃣ 配置模型 | 恒定比例、最小方差、权重约束与求解诊断 |
| 4️⃣ 回测分析 | 四策略统一滚动样本外回测、净值、成本、调仓日志、权重变化、绩效比较 |
| 5️⃣ 参数敏感性 | 252 / 504 / 756 交易日估计窗口、共同样本外区间、分年度研究 |
| 6️⃣ 研究结果 | 结果汇总、金融诊断结论、多工作表 Excel 导出 |

四策略：恒定比例 30/70、最小方差（样本协方差 / long-only / 权重和为 1）、100% 债券买入持有、恒定比例 10/90。**不预设最小方差更优**，结论由样本外结果给出。

## 二、数据来源与口径（不因部署而改变）

| 资产 | 代码 | 口径 | 来源 |
|---|---|---|---|
| 沪深300全收益指数 | `H00300` | 全收益（含样本股现金股息再投资） | 中证指数有限公司官网 `csindex.com.cn` |

详细口径、验证结果与回测假设见 [`DATA_SOURCES_AND_LIMITATIONS.md`](DATA_SOURCES_AND_LIMITATIONS.md)。

## 三、本地运行

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/streamlit run app.py --server.port 8503
```

打开 `http://localhost:8503`。**不需要任何 Token 或 `.streamlit/secrets.toml`**：本版本完全不依赖 iFinD 接口。

## 四、Streamlit Community Cloud 部署

1. 在 GitHub 创建**私有**仓库，把本目录作为仓库根推送（见第六节）。
2. 登录 [share.streamlit.io](https://share.streamlit.io)，用 GitHub 账号授权。
3. **New app** → 选择该私有仓库、分支 `main`（或发布分支）、入口文件 `app.py`。
4. Advanced settings：Python 版本选 **3.13**（本目录已提供 `runtime.txt`）；**Secrets 留空**（不需要）。
5. 部署后首次访问会从公开接口获取两个指数的历史行情（约数秒）；磁盘快照若被清空会自动重新获取。

> **必须先在云端实测**：能否访问 `csindex.com.cn` 与 `yield.chinabond.com.cn` 取决于云平台的出站网络策略，本机无法代为验证。若云端无法直连这两个域名，网页会明确显示失败原因；此时可在页面1「上传自有资产」中使用**有权使用且口径一致**的真实数据文件，**不得改用模拟行情或不同口径指数**。

### 缓存与磁盘

- `st.cache_data`（进程内，1 小时）＋ `data_sources/persistent_cache.py`（逐资产磁盘快照）。
- 云端磁盘**不保证可写或永久保留**：写盘失败时自动降级为进程内缓存并明确提示，不会导致网页不可用；重启后重新从公开接口获取。
- 时间判断统一使用**北京时间（UTC+8）**，不依赖服务器本地时区。
- 接口失败时回退最近一次通过质量校验的真实快照，并明确标注「本地快照（非实时）」，绝不冒充实时行情。

## 五、数据与授权声明（公开/分享前请确认）

- 页面6 的 Excel **仅导出衍生计算结果**（收益序列、权重、绩效、回测记录），**不导出原始行情点位、不提供原始行情批量下载**、不公开用户上传的数据。
- 页面1 只展示**期初=1 的标准化净值**用于形态观察，不展示原始点位序列。
- 指数数据的著作权与数据库权益归各指数编制机构所有。**能否在公开网页展示或对外分享衍生结果，须由使用者自行核对该机构的服务条款 / 数据使用许可**；本项目不对"接口可访问"等同于"可公开再分发"作任何主张。
- 因此**建议以私有方式部署、仅邀请指定研究者访问**（例如 Streamlit Cloud 的私有应用 + 邀请邮箱），不要设为完全公开。
- `v1_reference/asset_data_loader.py` 仅用于解析使用者自行上传的历史数据文件，**不调用 iFinD API、不读取任何 Token**；iFinD 相关实验代码不在本部署版内。
- 仓库不含 `.streamlit/secrets.toml`、Token、Access/Refresh 凭据、`.env`、虚拟环境、本地缓存与受限行情文件（见 `.gitignore`）。

## 七、已知局限

- 夏普比率基于 `rf = 0` **零基准假设**，不是真实无风险利率下的超额收益。
- 交易执行为「t 日收盘后产生信号 → t+1 日按收盘价近似成交 → t+2 日起新权重产生收益」，与日频数据一致但非真实撮合。
- CAGR（按实际日期年化）、年化几何收益（按 K=252）、年化算术收益是三个不同指标，页面分别列出，不可混用。
- 2019 与 2026 为**不完整年度**，其年度收益不得当作全年收益或年化收益。
- 最小方差权重高度集中于债券，单区间、单参数结果**不构成策略有效性证明**；本阶段未做参数寻优。
- 云端网络可达性、多并发下的响应速度、Community Cloud 资源限制，均需部署后实测。
